# Projeto-LogTech-IA

Trilha de aprendizagem DEV.

## Sobre o projeto

Este trabalho foi desenvolvido no **1º semestre** da disciplina de **Engenharia de Prompt e Aplicação em IA**. O projeto **Mapa Dev** é uma plataforma educacional para iniciantes em tecnologia: o usuário responde a um quiz de afinidade, descobre qual área combina mais com ele (Frontend, Backend, Full Stack, DevOps, Mobile ou Data) e recebe uma trilha de estudos personalizada, com apoio de um professor virtual de IA.

## Materiais do projeto

- **PROMPT_Gem**: prompt de instrução do Gem "Professor Trilha IA", com persona, contexto, exemplos (few-shot), formato de resposta, autoavaliação e regras de comportamento.
- **Mapa_Dev_-_Documentacao_do_Projeto**: documentação completa do projeto.
- **fluxograma_site**: diagrama do ecossistema, mostrando o fluxo entre usuário, quiz, processamento, resultado, plataforma de estudos e dicionário de IA.

## Arquivos do repositório

- `mapa-dev.zip`: versão inicial do site.
- `mapa-dev-completo.zip`: versão completa do site.
